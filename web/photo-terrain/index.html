按图生成地形

上传一张地图照片（示意图），蓝色部分当作海洋，其余颜色当作陆地（平原），一键生成可放回游戏的 .btl 文件。同一套规则与「Terrain Editor 正式版」App 保持一致。

1. 选择照片（选完直接出结果）

照片不用和地图格数一致，会自动拉伸铺满整幅地图；逐格取的是六边形中心的颜色。 照片里的文字、标注、线条会被当噪声丢掉，自动归到周围区域，不会变成一格一格的黑白地形。

2. 地图尺寸（可选）

高填 0 表示按照片长宽比自动算。改了尺寸会立刻重新生成。

3. 模板 .btl（可选，想要能直接进游戏就传）

建议用游戏 bin/ 里的空白关卡文件（例如 stage10001.btl）做模板。
不传模板就按上面的尺寸生成一张标准空白战役（主数据+军团+地形+省规划+归属，无城市/兵种/事件）。

4. 结果

彩色图就是生成出来的地形（蓝=海洋、绿=陆地平原），下载 .btl 直接放进游戏 bin/ 目录。

规则

蓝色 色相 180°~256° 且有饱和度 → 海洋（地形组 1 / 编号 0）
其他颜色 紫、白、灰、绿、红… → 陆地（平原）（地形组 0 / 编号 255）
文字/线条 深灰黑色的字、细线条 → 丢掉，用周围区域填平

海洋格自动按官方算法补海岸线波浪（装饰组 31），并把省规划写成 65535（游戏硬要求）；陆地格清掉残留波浪。

选一张照片就会立刻生成。上面的彩色六边形就是结果：深蓝=海洋，绿=陆地（平原）。
