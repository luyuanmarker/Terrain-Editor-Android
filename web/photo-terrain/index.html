按图生成地形

上传一张地图照片（示意图），蓝色部分当作海洋，其余颜色当作陆地（平原），一键生成可放回游戏的 .btl 文件。同一套规则与「Terrain Editor 正式版」App 保持一致。

1. 选择照片

照片不用和地图格数一致，会自动拉伸铺满整幅地图；逐格取的是六边形中心的颜色。

2. 地图来源

建议用游戏 bin/ 里的空白关卡文件（例如 stage10001.btl）做模板。
指定尺寸时，只写「主数据 + 军团 + 地形 + 省规划 + 归属」基础段，不包含任何城市/兵种/事件。

3. 生成

生成后可下载文件，直接放进游戏 bin/ 目录；不满意重新生成即可。

规则

蓝色 色相 180°~256° 且有饱和度 → 海洋（地形组 1 / 编号 0）
其他颜色 紫、白、灰、黑、绿、红… → 陆地（平原）（地形组 0 / 编号 255）

海洋格自动按官方算法补海岸线波浪（装饰组 31），并把省规划写成 65535（游戏硬要求）；陆地格清掉残留波浪。
