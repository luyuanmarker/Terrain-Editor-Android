它是什么

一个专门给《世界征服者4》做地图/关卡的工具，跑在安卓手机上。

📱手机上就能用

躺床上改地图：拖动缩放界面、手指涂地形、点一下放兵种，不用开电脑、不用装 Java 环境。

🧩按游戏规则改

官方 MapEdit 的段结构、海岸线算法、省区规则、海洋区划 65535 这些"硬要求"都按官方来，改完进游戏不崩。

🎨支持你自己的模组

导入解包后的模组文件夹（或 apk），国旗、兵种图标、建筑、地形贴图、将领头像、国家/兵种数值全换成模组那套，还能直接浏览模组里上千个 btl。

功能亮点

从地形到内容，从单格到整图，一整套都在里面。

🗺️地形

  • 31 种地形笔刷，笔刷范围 0~5 圈
  • 官方海岸线算法自动补波浪
  • 随机地形（按概率、可选地形组）
  • 导入照片一键生成地形：蓝色=海洋，其余=陆地

🏙️城市与建筑

  • 小城~大都市、机场、军港、要塞、工厂、核电站…
  • 32 字节全字段可改，新放的城市可当新省区
  • 国家归属带国旗选择，建筑上显示设施图标

🎖️兵种与军团

  • 点图标 → 点地图，连点批量放兵（船/陆军自动分水陆）
  • 等级、编制 1~4、方向、将领、技能、勋章
  • 军团列表 + 国家配置表（75 列），改国家颜色

🧭省区与归属

  • 取省 / 刷省笔刷、省区撤销
  • 按省着色渲染，城市归属直接改

📜事件编辑

  • 44 字节事件全部 15 个字段可改
  • 触发方式/事件类型下拉（回合到、消灭单位、刷兵…）
  • 新增 / 复制 / 删除 / 清空 + 字段说明

📐地图尺寸

  • 四方向扩展 / 收缩（内容坐标自动重映射）
  • 截取地图（起点→终点框选）
  • 生成 world.bin、校验并修复

模组支持 （重点功能）

想让编辑器显示你模组里的旗帜和图标？导入一次就行。

三步搞定

  1. 首页左下角点「模组」→「导入模组（文件夹）」，选解包后的模组目录（含 assets），也可以直接选模组 apk
  2. 编辑器自动从 tacticalmap、image_flags_hd、buildings_hd、terrain_hd 等图集里切出素材，按内置目录结构存好
  3. 之后打开任何地图，显示的国旗、兵种图标、建筑、地形贴图、将领头像、国家与兵种名字，全按你的模组来

连地图一起管

  • 模组里 assets/stage 的上千个 btl 直接列出来：搜索框 + 战役/征服/事件分区，不用翻
  • 打开征服自动读模组对应的 world{N}.bin 底图，不用手动选
  • 改完点保存 → 直接覆盖回模组里那个 btl，覆盖前自动备份到 地图编辑器/模组备份/
  • 没有导入模组？那就用编辑器自带的素材，功能一样完整
