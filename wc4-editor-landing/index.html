这编辑器是按游戏实际的 BTL 二进制格式做的，不是套壳改内存。你能看到的数据，基本就是文件里真正的数据： 兵种 48 字节一条、军团 300 字节一条、建筑 32 字节一条，字段都是对着格式一个个对出来的。 所以改完保存，游戏里是什么样就是什么样，不会"看着改了结果没用"。

目前能做的

地形

笔刷涂地形、随机地形、扩展地图（上下左右）、框选截取，陆地海洋随便画。

城市

加城市、改建筑全部字段、给城市设国家归属（直接选国旗），新放的城市也能编辑。

兵种

图标选兵种、改 48 字节全字段、编制用下拉框、随机兵力、批量放置。

省区规划

取省/刷省笔刷，按住拖动连续划省，省区颜色叠在地形上，带编号，画错能撤销。

国家 / 军团

军团列表、国家颜色、新建国家、改军团 300 字节数据。

BTL 主数据

版本、地图序号、胜利条件、战役时代、事件编辑。打开 APK 也能直接读里面的地图文件。

使用流程

1. 打开文件

战役 stage、征服 conquest、world.bin / map.bin，或者 APK 里的地图。

2. 改

地形、城市、兵种、省区、国家，改到你满意。

3. 保存

导出 btl / bin。征服的地形和关卡要一起保存。

4. 放进游戏

文件放回游戏数据目录的 bin/ 里。强烈建议先备份原文件。

一些说明

支持哪些文件？

战役 stageXXXX.btl、征服 conquestXXXX.btl、世界地形 world.bin / map.bin，还有 APK 压缩包里的 .btl / .bin。

要 ROOT 吗？

不用。编辑器只需要存储权限。把文件放回游戏目录那步，看你手机怎么处理，跟编辑器无关。

改坏了怎么办？

改之前备份原文件。编辑器里有撤销，但最保险的还是备份。
