# WC4 地形编辑器 宣传页

单文件静态页面（无任何依赖），手机/电脑浏览器都能直接打开。

## 上线到你的服务器（宝塔 / dx.xckeji.xyz）

1. 把整个 `wc4-editor-landing` 文件夹上传到网站根目录，例如：
   `/www/wwwroot/dx.xckeji.xyz/wc4-editor-landing/`
2. 浏览器打开 `https://dx.xckeji.xyz/wc4-editor-landing/` 即可访问。
3. 想当首页用，就把 `index.html` 的内容放到站点根目录的 `index.html`。

## 发布后要改的两处

- **下载按钮**：`index.html` 里 `id="dlBtn"` 的 `href`，改成 APK 的实际下载地址
  （比如先把 APK 传到服务器，再填 `https://dx.xckeji.xyz/download/地形编辑器测试版.apk`）。
- **作者信息**：页脚和"复制群号"旁的作者【】占位改成你的名字/B站ID。
