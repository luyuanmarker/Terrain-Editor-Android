WC4 地形编辑器（移动端测试版）

这是一个面向 Android 的《世界征服者4》（World Conqueror 4，简称 WC4）自定义地图/地形编辑器（非官方第三方工具）。工具可以打开、编辑并保存游戏的 BTL/BIN 地图格式，支持可视化的六边形地形编辑、建筑放置、画笔/魔棒（多选）工具、底图（导入并采样颜色）、图填（引导图）等功能，方便制作或修改自定义战役地图。

重要声明
- 本项目为第三方开发，与原游戏公司无关。请在合法合规的前提下使用本工具。代码内有启动时显示的免责声明（MainActivity.showDisclaimerOnce）。使用本工具造成的一切后果由使用者自行承担。

1. 项目解决什么问题
- 为 WC4 地图编辑提供一个移动端（Android）可视化编辑器，允许用户：
  - 读取游戏原始 BTL/BIN 地图文件并在手机上可视化显示；
  - 直接编辑地形类型、放置或移除建筑；
  - 使用画笔（圆形半径）、魔棒（连通区域多选）、多选后批量替换地形或建筑；
  - 导入参考图/底图并按格采样颜色以辅助手动上色（图填模式支持将原图铺在上方但保留已编辑格子）；
  - 随机生成地图、扩展地图尺寸并正确修正 BTL 二进制内部结构；
  - 保存为 BTL 或 BIN 格式以便在游戏中使用（saveAsBTL/saveAsBIN）。

2. 主要功能（源码实现可查）
- 文件支持：BTL（游戏战役文件）与 BIN（自定义二进制）加载与保存（参见 app/src/main/java/com/xckeji/bj/file/FileParser.java）。
- 可视化编辑：六边形网格渲染，地形图块贴图与纯色采样（app/src/main/java/com/xckeji/bj/render/HexMapView.java）。
- 地形编辑工具：
  - 画笔模式（brushMode）：按半径圈数涂抹地形并记录已编辑格子。
  - 魔棒/多选（magicWandSelect）：基于地形组或精确 ID 的连通区域多选。
  - 单格选择：显示选中边框并在右侧面板显示信息（见 MainActivity）。
- 建筑支持：放置/移除建筑、读取 BTL 中的建筑信息并写回（MapData.manage buildingIds）。
- 地图尺寸操作：扩展地图、向上扩展并修正 BTL 中所有相关索引（见 MainActivity.expandMap/expandMapUp）。
- 引导图/底图功能：导入图片作为底图并对每个格子采样颜色，或作为引导图（图填）覆盖并保留已编辑格子显示地形。
- 撤销/重做历史（OperationHistory 支持在编辑前保存快照）。
- 缩放/平移手势、双指缩放、单指拖动、长按移除建筑、音效与背景音乐开关。

3. 安装方法（开发/调试环境）
先决条件：
- Java 11（源码编译目标为 Java 11）
- Android SDK（建议通过 Android Studio 安装）
- gradle wrapper（项目包含 gradlew，可直接使用）
- 如需在真实设备上安装：启用开发者选项并允许 USB 调试；对于 Android 11+（API 30+）若需要访问外部存储请手动允许“全部文件访问”（MANAGE_EXTERNAL_STORAGE）权限（应用启动时会引导打开设置页面）。

从命令行构建并安装（通用步骤）：
1. 打开终端并切换到项目根目录（含 settings.gradle.kts 与 gradlew 的目录）。
2. 构建 APK（调试版）：
   ./gradlew assembleDebug
3. 安装到已连接的设备或模拟器：
   adb install -r app/build/outputs/apk/debug/app-debug.apk

或使用 Android Studio：
- 直接用 "Open" 打开项目根目录，等待 Gradle 同步后，用 Run/Debug 按钮在模拟器或真机上运行。

4. 使用方法（App 内操作说明）
- 启动后：第一次启动会显示免责声明，需确认才能进入编辑界面。
- 顶部工具栏（MainActivity.createTopBar）常用按钮说明：
  - 撤销（Undo）: 撤销上一步操作。
  - 开启/关闭音乐、音效：控制背景音乐与音效。
  - 打开：选择并加载本地 BTL/BIN 文件（文件选择器）。
  - 保存：将当前地图保存（保存格式由实现决定，支持 BTL/BIN）。
  - 随机生成：生成一个随机地图（用于新建地图）。
  - 随机地形：随机化当前地图地形。
  - 预览（切换右侧面板可见性）：显示或隐藏右侧工具面板。
  - 底图：导入底图（overlay），程序会按格采样颜色并可开启/关闭底图显示。
  - 图填：导入引导图（Guide），在图填模式下原图会覆盖网格但保留已编辑的格子。
  - 遮罩：切换底图/引导图显示（具体交互见右侧面板）。

- 主要交互：
  - 点击六边形格子选中该格，右侧面板显示格子信息（地形组、地形 ID、建筑等）。
  - 长按格子：移除该格的建筑（long press 在 HexMapView 中实现）。
  - 双指缩放：以双指中心为锚点缩放地图。
  - 单指拖动：平移地图视图。
  - 画笔模式：在右侧选择要涂的地形组并启用画笔模式，然后单击/拖动进行涂抹。
  - 笔刷半径：右侧可设置圈数（radius）以控制一次性涂抹范围。
  - 魔棒（多选）：在地图上选中一个格子并使用“魔棒”功能，会选择与起点连通且满足相同地形组或精确 ID 的区域；可以对选中区域批量替换地形或建筑。
  - 批量应用：在多选状态下，右侧有“应用地形/应用建筑”之类的按钮来一次性修改选中格子。

- 导出与兼容性：
  - 保存为 BTL：支持基于原始 BTL 数据进行更新或在无原始数据时按游戏格式生成新的 BTL（参见 FileParser.saveAsBTL）。
  - 保存为 BIN：可导出为简化的 BIN 格式（16 字节头 + 每格 16 字节地形描述），用于测试或自定义用途。
